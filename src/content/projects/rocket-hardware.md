Sugar Rocket is an independent project to design a sturdy, lightweight rocket using heat-resistant materials such as graphite for the nozzle. The project is currently in the design stage.

## My role

I lead the CAD design, programming, and development of this project. Current design work includes the nozzle, combustion chamber, and remote activator.

## Nozzle hardware

The project files include a nozzle assembly, a graphite insert, a nozzle carrier, and a propellant grain mold. The carrier has a SolidWorks model, a drawing, and DXF, STEP, and STL exports. These files document the component geometry and how the design is prepared for technical handoff.

## Current design work

The project description identifies subsonic, sonic, and supersonic nozzle diameters as design calculations still in progress. No launch or measured performance result is claimed here: the project remains in its design stage.

## What this project demonstrates

Independent CAD development across related rocket hardware, maintaining the nozzle carrier’s model and drawing outputs, and documenting a design before presenting it as a completed build.
